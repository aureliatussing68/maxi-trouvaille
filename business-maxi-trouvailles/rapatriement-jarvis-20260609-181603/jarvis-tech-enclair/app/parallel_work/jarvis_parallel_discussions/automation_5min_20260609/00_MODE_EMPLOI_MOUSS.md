# Paquet discussions paralleles Jarvis/Mimouss - automation 5 minutes

Objectif: ouvrir plusieurs discussions paralleles pour aider le fil principal, sans casser le PC de Mouss ni activer d'actions sensibles.

Mode d'emploi rapide:
- Ouvre une discussion parallele par fichier `01_` a `10_`.
- Colle le contenu complet du fichier dans la discussion.
- L'agent doit creer ou maintenir une automatisation active toutes les 5 minutes pour son propre fil.
- Le fil principal Jarvis reste le seul integrateur final.
- Les fichiers `99_` sont optionnels pour superviser/trier les retours.

Regle importante:
- Les agents paralleles produisent des rapports, patches proposes, tests et fichiers dans leur dossier atelier.
- Ils ne doivent jamais publier, acheter, payer, envoyer un mail reel, supprimer, connecter un compte, capturer camera/micro, ouvrir une fenetre visible, lancer un runtime, ni afficher de secrets.
- Les domaines sensibles restent en HOLD ou brouillon jusqu'a validation manuelle finale de Mouss.

Retour attendu de chaque agent:
- Ecrire son retour dans `parallel_work/jarvis_parallel_discussions/returns/`.
- Utiliser un nom stable: `NN_track_latest.md` plus un rapport horodate si besoin.
- Terminer chaque cycle par: GO / HOLD / STOP, fichiers, tests, risques, prochaine couche.
